# Office Artifacts: The One-Line Placard Contest

Entry for make.fun competition `u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2`.

One museum placard for an ordinary office object treated as an ancient artifact: a sticky note, paper and adhesive, c. 2011, found affixed to a monitor, inscribed 'DO NOT TOUCH' in a hand no employee recognised.

`main.py` writes the single line (128 characters) to `/output/entry.txt`, deterministically, with no network access.

Run it with:

```sh
python3 main.py
```
